# Знак Pinly

Оригинал — `logo-source.webp` (1024×1024, белый фон, сгенерирован в Recraft).
Из него собраны векторные и растровые файлы в `public/brand/`.

## Что где

| Файл | Что это | Где применять |
| --- | --- | --- |
| `public/brand/logo.svg` | Цветной знак, два слоя: тёмный силуэт + мятная лента поверх, мятный слой обрезан по силуэту через `clipPath` | шапка, заставка, футер |
| `public/brand/logo-mono.svg` | Один контур на `currentColor` | ч/б печать, водяные знаки, места, где цвет темы задаётся CSS |
| `public/brand/logo-mark.png` | 512×512 RGBA, растр из `logo.svg` | `LogoMark.tsx` до перехода на SVG, OG-картинки |
| `public/brand/favicon.ico` | 16/32/48/64 | `src/app/favicon.ico` |
| `public/brand/apple-touch-icon.png` | 180×180 | iOS «на главный экран» |
| `public/brand/og-square.png` | 512×512, непрозрачный белый | квадратные превью в соцсетях |

## Палитра

| Роль | Hex | Откуда |
| --- | --- | --- |
| Мятная лента (передний план) | `#2fbf9b` | совпадает с токеном `--accent` |
| Тёмно-зелёная подложка | `#0f7f66` | совпадает с `--accent-strong` |

Обе краски взяты из токенов `globals.css`, а не из пикселей исходника: в исходнике
было `#38c0a0` и `#087050`, это на пару шагов мимо брендовой палитры.

## Как пересобрать

```bash
python docs/brand/build-logo-assets.py <папка-с-logo_clean.png> public/brand
```

Скрипт ждёт на входе `logo_clean.png` — исходник с вырезанным фоном (белый → альфа,
матирование по двум известным краскам). Дальше он раскладывает пиксели по ближайшей
краске, трассирует каждый слой кубическими Безье (Schneider) и пишет оба SVG.

Порядок слоёв важен: тёмная подложка — это **весь силуэт**, мятная лента лежит
поверх. Если рисовать две фигуры встык, на стыке остаётся светлая щель от
анти-алиасинга; поэтому мятный слой шире и обрезан `clipPath` по силуэту.

## Проверки

- Точность против оригинала: средняя разница 3.6/255, пикселей с расхождением
  больше 40 — 0.9% (это кромка, где сглаживание неизбежно).
- Читается от 16 px: точка над «P» на 16 px сливается с буквой в кляксу, но
  силуэт «P» остаётся узнаваемым. Для 16 px лучше `logo-mono.svg`.
- На тёмной теме `#0e0f11` контраст мятной части 8.3:1, тёмной 3.9:1 — оба выше
  порога 3:1 для графики.
